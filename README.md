# 👟 Sneakers eCommerce App

A modern, high-performance eCommerce mobile application built with **Flutter** and **Dart**. This project demonstrates a complete shopping experience, featuring a responsive UI, state-managed cart functionality, and a modular architecture.

## 🚀 Features
*   **Dynamic Product Catalog:** Browse a wide range of sneakers with detailed descriptions and high-quality imagery.
*   **Advanced Cart Management:** Add, remove, and update items in real-time with persistent state management.
*   **Responsive UI/UX:** Optimized for various screen sizes across both iOS and Android platforms.
*   **Smooth Animations:** 60 FPS transitions and interactions for a premium user feel.
*   **Search & Filter:** Easily find specific models or brands using the integrated filtering system.

## 🛠 Tech Stack
*   **Framework:** [Flutter](https://flutter.dev)
*   **Language:** [Dart](https://dart.dev)
*   **State Management:** Provider / Bloc / GetX
*   **Architecture:** MVVM (Model-View-ViewModel)
*   **IDE:** Optimized for [Visual Studio Code](https://code.visualstudio.com)

## 📦 VS Code Setup & Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com
    ```
2.  **Open in VS Code:**
    ```bash
    code Sneakers_eCommerce
    ```
3.  **Install Recommended Extensions:**
    When prompted by VS Code, install the **Dart** and **Flutter** extensions.
4.  **Fetch Dependencies:**
    Press `Ctrl + Shift + P` (Cmd + Shift + P on Mac) and type:
    > **Flutter: Get Packages**
5.  **Run & Debug:**
    Press **`F5`** to launch the app on your selected emulator or physical device.

## ⌨️ VS Code Productivity Tips
